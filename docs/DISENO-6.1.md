# Reparto aprobado de Occidentale 6.1

Documento histórico: la [versión 6.2](DISENO-6.2.md) cambia la tecla debajo de Escape y Mayús+punto.

| Posición o secuencia | Resultado |
|---|---|
| Antigua tecla Ñ | ; / : |
| Grave muerto + c/C | ç/Ç |
| Grave muerto + s/S | ß/ẞ |
| Grave muerto + n/N | ñ/Ñ |
| Grave muerto + d/D | đ/Đ |
| Shift+grave, después a/o | ã/õ y mayúsculas |
| Shift+6, después vocal | â ê î ô û y mayúsculas |
| Agudo muerto + s/S, t/T | ș/Ș, ț/Ț |
| Shift+coma, después s/S | ś/Ś |
| Antigua tecla +, después a/A | å/Å |
| Antigua tecla +, después o/O | ø/Ø |
| Antigua tecla +, después u/U | ů/Ů |
| Shift+antigua tecla +, después vocal | ā ē ī ō ū / Ā Ē Ī Ō Ū |

El grave de las secuencias es el muerto a la derecha de P. El grave literal de la esquina superior izquierda conserva sus símbolos. Los acentos seguidos de Espacio permiten escribir el símbolo correspondiente; Shift+6 seguido de Espacio escribe ^.

+ y * siguen en la fila numérica. Las combinaciones AltGr de corchetes y llaves se conservan. AltGr+O y AltGr+A siguen dando œ/Œ y æ/Æ. Shift+punto conserva : y queda reservado para otra decisión.

El prefijo de Shift+coma es distinto del agudo normal para que ś y ș no se confundan. Las reglas personalizadas requieren `user-install` y un nuevo acceso a la sesión.

El inventario reproducible de LENGUAS.md comprueba 57 lenguas: 55 repertorios principales completos. Los huecos restantes están identificados, al igual que los caracteres auxiliares y las lenguas sin datos suficientes. No equivale a soporte completo de todas las aplicaciones ni de la tipografía de cada lengua.
